# Tuck-in (턱킨)

**노치 밑에 쏙 들어가는 macOS 할 일 위젯.** 노치에 마우스를 올리면 다이내믹 아일랜드처럼 펼쳐집니다.

- 🌐 **랜딩·다운로드**: https://lyg2798.github.io/tuck-in/
- 📦 최신 릴리스: [Releases](https://github.com/lyg2798/tuck-in/releases)
- 요구사항: macOS 14+ · Universal (Apple Silicon/Intel) · 서명·공증된 앱
- 데이터는 전부 로컬(`~/Library/Application Support/TodoWidget/`)에만 저장됩니다 — 서버·계정·수집 없음.

이 저장소는 랜딩 페이지(GitHub Pages)·릴리스 파일·자동 업데이트 피드(`appcast.xml`)를 호스팅합니다.
